docs/paper_spec.md §1–4 · pp. 3–12

How the model works

The SNB does not forecast the CPI directly. It forecasts each expenditure item separately and adds the forecasts up with the CPI weights. The replication follows the same chain.

Data

CPI item panel

Federal Statistical Office item indices, chain-linked across bases. 217 items in 2013, ~182 kept consistently.

Item models

One model per item

  • ARIMA(p,1,q), order by SIC
  • seasonal AR at lag 12
  • quarterly lags for quarterly items
  • ad-hoc rules as fallback
  • oil: ECM · rents: mortgage rate
Aggregate

Chained Laspeyres

Item forecasts weighted with that year's CPI weights, chained via December of the previous year.

Target

Quarterly y-o-y

Inflation of the quarterly average index, horizons h = 1–5 quarters. h = 1 is the current quarter, with 2 months known.

Evaluate

2004–2011

RMSFE, relative RMSFE and DMW tests against AR(1), ARIMA(1)/(6)/(14), consensus and the SNB forecast.

.claude/skills/skill-feedback-loop · docs/skill_feedback.md

Feedback loop for the skills

Skills are instructions that later sessions follow without question, so a wrong line repeats in every later task. The loop turns what actually happened into small, tested edits.

  1. Capture

    Your corrections, steps the agent had to improvise, wrong instructions, failed checks, and your notes on this page.

  2. Triage

    Wrong, missing, unclear, trigger, bloat, project fact or one-off. Facts go to the project docs, not into skills.

  3. Patch

    The smallest edit that fixes it, with the evidence attached. Applied only after your yes.

  4. Verify

    A regression scenario in the skill's evals.md. A fresh subagent plans from the edited skill, and its plan is graded.

  5. Record

    Log row updated, your feedback marked applied or rejected with a reply, this page republished.

↺ the next task runs on the improved skill

Micro retro · after every task

Did you correct me? Did I improvise a step or skip one? Was an instruction wrong? Did a check fail? Each finding is logged. Only obvious fixes are applied straight away.

Processes the open findings and this inbox, checks the skills against each other and against AGENTS.md, removes lines that are never used, and tracks corrections per task. That number should keep falling.
