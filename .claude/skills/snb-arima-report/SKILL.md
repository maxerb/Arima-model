# SNB ARIMA — reporting (T6.1)

## Outputs
- `outputs/tables/*.tex` — `booktabs` tables generated by `src/arima_snb/report.py` from `outputs/tables/*.csv`
  (never type numbers by hand). Layout like the paper: horizons 1–5 as columns, first row absolute RMSFE, then relative
  RMSFE with `(p)` underneath, `\textbf{}` if p < 0.10, note under the table.
- `outputs/tables/compare_paper.tex` — side by side: paper | ours | difference, for Tables 1–4.
- Figures (PNG + PDF, consistent style, readable in black-and-white): Chart 1 (rice vs trousers), Chart 2 (forecast fans
  vs actual, total and excl. oil), Chart 3 (trousers interpolation), Chart 4 (reaggregated vs official), plus extension
  figures (rolling relative RMSFE, error vs oil price change). Use the `dataviz`/`data:create-viz` skills for styling if available.
- `docs/methods_draft.md` — methods section draft: data, item models, special models, aggregation, evaluation, extension.
  Cite paper pages. Each deviation references its decision ID and is explained in plain words.

## Procedure
1. Regenerate all CSV tables via the evaluation scripts (don't trust stale files; check timestamps vs code).
2. Generate `.tex` and figures into `outputs/`. The thesis document lives in a separate repository: never write into it.
   Tell the user which files to copy (or how to reference this repo, e.g. as a git submodule) — ask before assuming.
3. Write the replication assessment: for each table, does the ranking and significance pattern match? Where not, list
   plausible causes in order (data coverage, item mapping, add-factors, real-time vintages, decisions D-xx).
4. Build the "Deviations from the original" table straight from `docs/decisions.md`.

## Checks
- Every number in a `.tex` file traces to a CSV in `outputs/` (report.py writes a header comment with the source file and git hash).
- Tables compile in a minimal LaTeX document (`latexmk -pdf` in a temp dir) if LaTeX is installed.
- Figures have axis labels with units, a source note ("Source: BFS, SNB, own calculations"), and the period in the title.
